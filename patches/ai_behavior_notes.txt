== AI BEHAVIOR TUNING (hardcoded with difficulty scaling) ==
Source: src/onthepitch/aitactics.hpp

  GetAttackingRunThreshold(counterAttack)   - 0.62 - CA*0.24 (when to make runs)
  GetAttackingRunDuration_ms(counterAttack) - 2800 + CA*2200ms (how long runs last)
  ShouldStartZonePressure(pressure, territory, distance) - whether to press
  GetZonePressureDuration_ms(pressure)      - 700 + pressure*1600ms
  GetDribbleForwardDrive(dribble, role)     - 0.55 + dribble*0.28 + role*0.12
  GetSupportWebScale(supportDistance)       - 0.68 + support*0.20
  GetDefenderSupportScale(roleMindset)      - 0.72 + role*0.52 (capped at 1.0)

Source: src/onthepitch/gameplaytuning.hpp

  GetFirstTouchContextPenalty() - pressure/fatigue penalty on first touch
  GetFatigueWorkloadFactor()    - sprint is 0.36 more taxing than jogging

== NO DEDICATED AGGRESSION/FOUL/TACKLE SLIDERS ==
The game does NOT have:
  - Explicit "aggression" slider
  - Explicit "tackling intensity" slider  
  - Explicit "foul frequency" slider
  - Explicit "running intensity" slider

Tackling/fouls emerge from:
  - team_pressure (higher = more pressing = more tackles)
  - match_difficulty (harder AI = better timing = fewer fouls)
  - Player attributes (individual player stats in database)

Additional game buttons (not in API yet):

  - e_ButtonFunction_TeamPressure - team press

== SUMMARY ==

Configurable via config file:
  - match_difficulty [0-1] - global CPU skill level

Configurable via database (per team):
  - 15+ tactical sliders affecting positioning, pressing, attack style

Hardcoded AI behaviors (not configurable without code changes):
  - Run timing thresholds
  - Pressure/tackle decisions
  - Fatigue model
  - Foul probability (implicit from pressure + timing)

To increase aggression/tackling without code changes:
  - Raise team_pressure to 1.0 for more zone pressing
  - Raise position_defense_microfocus_strength for tighter marking
  - These create more challenge situations but don't add explicit "tackle harder" mode
